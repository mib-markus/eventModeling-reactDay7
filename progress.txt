- **Learnings for future iterations:**
  - This project currently has no `.eventmodelers` board token/org configured (only
    `.eventmodelers/config.json` with `agentIds.BUILD`, no `token`/`boardId`/`organizationId`) -
    every board-dependent step (screen HTML fetch, update-slice-status, comments) has nothing to
    connect to. Treat this as expected per CLAUDE.md's "skip platform communication" rule rather
    than trying to run the `connect` skill's interactive setup mid-iteration.
  - Screen lane -> folder segment: `slice.json.screens[].lane` gives the lane directly without
    needing a board fetch when the board isn't reachable; use it as `laneSlug` (lowercased,
    hyphenated) same as the skill's Step 2 describes.
  - datetime-local `<input>` is the natural fit for `DateTime` typed fields with `YYYY-MM-DDTHH:mm`
    examples (matches slice.json's example format exactly, e.g. "2026-04-15T06:00").
